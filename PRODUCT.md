# End of Abyss Guide

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

English-speaking End of Abyss players checking a blocked route, missing weapon or return objective on a phone while playing. This audience and operating scene are recorded in AGENTS.md and the existing site.

## Product Purpose

Help a player identify a useful next action: diagnose an energy-node door, interpret a Scanner requirement, locate one of six weapons, distinguish death costs, or remember a return trip. User confirmed the existing guide facts and tools remain during the redesign.

## Positioning

A focused, independent guide with a door symptom helper, equipment-aware weapon lookup, local completion checklist and local return notebook. No account or game-save access. The site's differentiation is this combination of practical task aids and the verified game-specific advice already published.

## Operating Context

Players navigate directly from a search result or select a topic from the homepage. Guides cross-link to relevant tools and prerequisites. Notes and checklist state stay in the current browser. Optional analytics require consent.

## Capabilities and Constraints

Next.js static export hosted on Cloudflare Workers. Seventeen existing routes. Preserve canonical URLs, published metadata, factual claims, semantic internal links, dropdown navigation, persistent light/dark choice, tool behavior, local storage safety and consent. Do not invent a Steam release, map coordinates, boss thresholds, weapon DPS or upgrade costs. No active advertising keys. This is a design redesign, not a new research or indexing campaign.

## Brand Commitments

Name: End of Abyss Guide. User requested a complete redesign toward the craft of Awwwards, Webby Awards and FWA. User has no visual elements or effects that must be kept or avoided. Existing official game art and the custom game-derived favicon remain available assets; the old layout is an anti-reference, not a visual contract.

## Evidence on Hand

Verified facts and source ledger in ../end_of_abyss/_research/ and data/sources.json. Official facility imagery, three creator-video thumbnails, game-derived favicon and published route-specific content. No playthrough screenshots of every item and no real user testimonials; never manufacture either.

## Product Principles

- Put a player's next action within easy reach.
- Build atmosphere from the actual game rather than invented lore.
- Give guides a readable structure and useful reciprocal links.
- Keep private notes local and analytics optional.
- Quality claims follow verified behavior and visual evidence; awards remain external judgments.

## Accessibility & Inclusion

Keyboard navigation, visible focus, semantic headings, readable contrast, touch targets, zoom, responsive layouts and reduced-motion support remain requirements.
